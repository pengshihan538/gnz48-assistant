# gnz48竞价切票助手

GNZ48 竞价的只读监控和座位价格参考工具。程序不会自动出价或购票。

首次使用：安装 Node.js 20 或更新版本，运行 `setup.cmd` 安装依赖；将 `account.example.json` 复制为 `account.local.json`，填入你自己的账号和密码，然后运行 `start.cmd`。本地账号文件已被 Git 忽略，不要上传或分享。

## 默认启动：原生桌面版（HTTP 爬虫）

双击 `GNZ48-Monitor.exe` 即可，或继续使用原来的 `start.cmd`。不需要打开 Edge、Chrome、图表网页或黑色命令窗口。请保持整个文件夹完整，不要只移动 EXE。

### 自动发现竞价、点开查看

启动后首先打开“竞价列表”，自动抓取 GNZ48 官网全部目录分页（目前 451 场 / 23 页）。目录包括历史场次；可按名称、日期文字或编号搜索，按普通座、VIP/尊享、站票等类型及状态筛选。双击一行，或选中后点“打开所选竞价”，即可读取该场全部出价记录。

“刷新竞价列表”重新同步目录；只有打开的当前场次会自动监控，并不会轮询 451 场的出价详情。切换时清除上一场的数据，首次打开场次才用本地配置登录，后续复用内存会话。目录价格和人数来自官网列表，详情排名仍按完整出价记录去重。

中间座位推荐仅对现金普通座开启，使用你提供的固定座位图；其他商品和积分竞价只显示价格分布与排名。不同公演的座位图若有变化，需先调整映射，不能以此保证座位。

桌面版读取同目录 `account.local.json` 的账号密码，用网站正常密码登录流程创建仅存在内存中的会话。已安装的 `playwright-core` 仅作为 HTTP 客户端，不启动浏览器。登录失败或需要额外验证时停止，错误显示在窗口底部。

- **理想座位**：9、10、8、11、7、12 排的中间区间，按你的偏好顺序；固定两列三行，无滚动条。卡片间距、文字与柱状图按可用窗口高度压缩，六个区域及其价格、人数和参考建议同时显示。排名只计每人最高价，同价按时间先后；同一毫秒的顺序及最终座位仍以官网为准。
- **价格分布**：全部价位在同一排显示，不换行、不分层，无横向或纵向滚动条；按窗口宽度和价位数量自动缩小柱宽、间距，必要时缩小标签。每根柱保留价格与人数，下方同时显示区间分布。
- **排名明细**：完整去重排名、最高价、北京时间出价时间和本人标记。
- **刷新**：进行中的竞价每轮成功后等待 30 秒再采集全部分页；手动刷新立即开始，3 秒内重复触发合并。不是每秒请求网站，也不与官网刷新时刻严格同步。
- **完整性**：逐页请求，每页 20 条，末尾复查首页；缺页、页数变化、重复记录或网络错误均不更新排名，保留上次数据并暂停建议。网站没有原子快照，采集期间仍可能发生变化。
- **结束与暂停**：网站标记已结束后自动停止轮询，保留界面并允许手动刷新；结束场不再建议出价。关闭窗口会停止自己的后台进程，不关闭任何浏览器。
- **时间**：固定北京时间 UTC+8，显示毫秒，定期通过官网时间接口校时。显示到毫秒不等于标准授时的毫秒精度，窗口明确标注往返延迟估算。

目标场次由竞价列表选择。第 **33444** 场实测 10 页、196 条原始记录、105 位去重竞拍者，完整采集约 1.4–1.9 秒；实际速度受网络与网站响应影响。未找到当前账号的出价时显示“—”，不会伪造排名。

程序不提交出价，不保证最终名次。账号文件请勿分享。无需新增安装浏览器或修改系统设置。

开发验证：`node --test tests/monitor.test.js`；原生控件自检：`powershell.exe -NoProfile -STA -File desktop.ps1 -ValidateOnly`；单次真实采集摘要：`node http-monitor.js --once --summary`。重新编译启动器使用 `build-desktop.ps1 -OutputName 新文件名.exe`。

## 纯 HTTP 账号密码登录测试

在 `account.local.json` 中填写 `username`、`password`，然后在本目录运行 `node http-login.js`。

- 使用官网密码登录入口，不启动 Edge 或其他浏览器；每次运行只提交一次登录请求。
- 登录后验证竞价页是否识别登录状态，不提交出价。
- 不输出账号、密码或会话内容；登录会话仅保留在测试进程内，退出后不保存。
- 网站要求短信、验证码或账号补充认证时停止，需本人在官网处理。
- `http-login.js` 仅测试登录；桌面版的 `http-monitor.js` 已实现 HTTP 全分页采集。

`account.local.json` 是明文文件，请勿分享或提交；已加入 `.gitignore`。

## 旧版浏览器监控器（保留备用，不再默认启动）

下面内容仅适用于旧版 `node monitor.js`；`start.cmd` 现在启动上方的桌面版。旧版浏览器文件未删除，避免影响你已打开的网页。

此工具每秒只读取浏览器内存中的价格、人数和第一页出价列表，不会每秒产生网络请求。它会显示账号当前最高出价、去重排名、目标座位区、价格区间人数和具体价位人数。检测到页面变化时会提前更新完整排名；页面未变化时每30秒刷新一次主页面。最后15分钟前完整分页最多每60秒同步一次，最后15分钟每30秒同步一次。

启动后会同时打开“理想座位竞价图表”标签页。每个目标排名区间都有独立的实际价格柱状分布，柱子标明价格和人数；右侧显示可行价范围、稳健建议价、预计排名及名次缓冲。稳健建议以区间靠前约三分之一为目标，避免只压在区间下沿。

## 安全边界

- 只读取页面，不会填写、点击或提交出价。
- 不会绕过登录、滑块验证码或网站限制。
- 推荐仅为当前数据下的保守估算，不能保证最终排名或座位。
- 同价时按“你现在出价会排在已有同价者之后”估算。
- 不设置推荐价格上限；具体价格分布会包含所有有效价格。

## 使用方法

1. 首次使用，双击 `setup.cmd` 安装本地依赖。
2. 双击 `start.cmd`。
3. 工具会打开一个独立的 Microsoft Edge 窗口。
4. 在该窗口中手动登录并完成滑块验证。
5. 回到黑色命令窗口按 Enter，之后保持两个窗口开启。
6. 建议在19:15前启动；19:25以后重点查看推荐。

登录状态保存在 `%LOCALAPPDATA%\GNZ48AuctionMonitor\edge-profile`，不会写入本工具目录。若网站主动使会话失效，仍需手动重新登录。

不要重复双击 `start.cmd`。工具只允许一个实例运行；若看到“登录配置被占用”，请关闭旧的监控专用 Edge 和旧命令窗口，再启动一次。

## 输出说明

- “当前第N名，建议暂不加价”：已经落在目标中间区间。
- “稳健建议价 ¥X”：按当前完整出价记录，以目标区间靠前约三分之一为目标计算。
- “当前数据下未找到可行价格”：当前参与人数或你的既有排名尚不支持进入该目标区间。

无论工具推荐什么，最终都应以页面显示和自己的预算为准。真实出价需要你本人确认并操作。
